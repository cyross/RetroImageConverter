# RetroImageConverter

レトロゲーム・PC向け画像コンバーター **RetroImageConv**

入力画像を、往年のパソコン・ゲーム機の画面仕様（解像度・ドット比・色数・パレット制約）に合わせて縮小・減色します。
当時の CG でよく使われた「タイリング（タイルパターンによる中間色）」や各種ディザリングに対応し、
98 時代の定番画像形式 **MAG** の読み込み・書き出しもできます。

- 出力形式: PNG（標準）/ JPEG / GIF / BMP / WebP（ロスレス）/ MAG
- 入力形式: PNG / JPEG / GIF / BMP / TIFF / WebP（※）/ MAG（16色・256色）
- 出力ファイルはフルカラー（24/32bit）で保存します（GIF・MAG はパレット形式）

※ WebP の読み込みには Windows の WebP 画像拡張機能が必要です（書き出しは内蔵エンコーダーで行います）。

## 構成

| プロジェクト | 内容 |
|---|---|
| `RetroImageConv` | GUI アプリ（Win32）。プレビューを見ながら設定・保存 |
| `RetroImageConvCLI` | コマンドライン版（一括変換向け） |
| `RetroImageCore` | 変換エンジン（静的ライブラリ、OS 非依存の C++20） |
| `RetroImageCoreTests` | コアのテスト（MAG 往復、全プリセットの制約チェックなど） |

## ビルド

- Visual Studio 2026（MSVC v145 ツールセット）、C++20
- `RetroImageConv.sln` を開いて `x64` / `Debug` または `Release` でビルド
- 出力先: `bin\x64\<構成>\`
- 外部ライブラリは不要です（画像の読み書きは Windows Imaging Component と内蔵コーデックを使用）

ツールセットの再ターゲットを求められた場合は、インストール済みのツールセットを選んでください。
`CMakeLists.txt` はコア・CLI・テストのビルド確認用の補助ファイルです。

## GUI の使い方

1. 「画像を開く」またはウィンドウへのドラッグ＆ドロップで画像を読み込みます。
2. 機種プリセットとモードを選ぶと、自動で変換・プレビューされます（推奨のディザ設定も自動で選ばれます）。
3. 必要に応じてサイズ・縦横比・色数・ディザ・タイリング・画質・アルファを調整します。
4. 出力形式を選び「名前を付けて保存」します。

プレビューは「変換後 / 元画像 / 並べて表示」を切り替えられます。ホイールで拡大縮小、ドラッグで移動、ダブルクリックでフィット表示に戻ります。
「ドット比を補正して表示」をオンにすると、640x200 などの縦長ドットを実機の見た目に近い比率で表示します。

## 変換オプション

### サイズ・縦横比
- **縮小**: 機種の解像度に合わせる / 元画像のサイズのまま / サイズ指定
- **縦横比**: 機種の画面比に揃える（引き伸ばし）/ 元の比率を保つ（余白あり・余白なし・切り抜き）
  - 機種のドット比（例: 640x200 は縦長 2:1）を考慮して比率を計算します
- **切り抜き範囲**（縦横比が「切り抜き」のとき）: 横位置・縦位置（0〜100%、50% = 中央）と拡大率（1.0〜4.0倍）
  - GUI では元画像の表示上に切り抜き枠が出ます。枠をドラッグして移動、枠の外をクリックするとその位置へ移動、Ctrl+ホイールで拡大率を変更できます
- **補間**: Lanczos3 / バイリニア / 面積平均 / ニアレストネイバー

### 色
- **色数**: プリセット通り、または 2〜256色・65536色・フルカラーに上書き
- **色差**: 加重 RGB / L\*a\*b\*
- **黒を必ず含める**（標準でオン）、**タイル/属性制約**（FC・PCE・SFC・GBC・MX などの制約を適用するか）
- **混色を線形光で計算**（標準でオン）: タイルや誤差拡散の混色を物理的に正しい線形光で計算します（実機 CRT の見え方に近い仕上がり）。オフにすると一般的な画像ツールと同じ sRGB 計算になります。

### ディザリング
なし / 組織的ディザ（2x2・4x4・8x8）/ 誤差拡散（Floyd-Steinberg・Jarvis-Judice-Ninke・Stucki・Atkinson・Sierra・Sierra Lite）。強度と蛇行走査を指定できます。

### タイリング
2 色のタイルパターンで中間色を表現する、88/98 時代の CG で定番だった手法です。パターンは画面座標に固定されるため、規則正しいタイル模様になります（MAG の圧縮効率も上がります）。

- **パターン**: 市松（50%）/ 2x2 タイル（25・50・75%）/ 4x4 タイル（1/16 刻み）/ 縦縞 / 横縞
- **配色の傾向**
  - **88風**: デジタル8色では「1 成分だけ違う色同士（赤＋黄＝橙など）」と「黒・白との混色（暗色・淡色）」に限定し、補色同士の濁った混色を避けます
  - **98風**: 近い色同士だけを混ぜ、16色パレットでも滑らかなグラデーションにします
  - **制限なし**: すべての組み合わせを使います
- 誤差拡散と組み合わせると、タイルの段階を誤差拡散で滑らかにつなぎます（ハイブリッド）

### 画質調整・アルファ
- 明るさ・コントラスト・彩度・ガンマ
- アルファ: 背景色と合成 / アルファを保持 / 2値化（しきい値指定）

### 出力
- 形式、JPEG 品質、ドット比補正出力（640x200→640x400 など）、整数倍拡大
- MAG 保存時のユーザー名（18バイトまで）・メモ（Shift_JIS で保存）

## MAG フォーマット

MAG（MAKI02）形式の 16色・256色画像の読み込みと書き出しに対応しています。

- 読み込み時はスクリーンモードの 200 ライン指定（縦長ドット）を反映し、部分セーブ画像の範囲も切り出します
- コメント（機種名・ユーザー名・メモ）を表示できます（GUI:「ツール → MAG 情報」、CLI: `--info`）
- 保存時はプリセットに応じたスクリーンモード（例: 98 アナログ16色 = $00、88 デジタル8色 = $07）を設定します
- 4bit 階調のパレットは MAG の慣例どおり下位ビットを 1 で埋めて保存します

MAG フォーマットは まきちゃんネット で策定された画像形式です（仕様書: Woody RINN 氏）。
仕様書の規定（フォーマットの使用は自由）に基づいて独自に実装しています。

## コマンドライン

```
RetroImageConvCLI <入力> [-o 出力] [オプション]

  --list                      プリセットとモードの一覧
  --info                      MAG の情報を表示
  -p, --preset ID             機種プリセット (既定: 98)
  -m, --mode N|ID             モード番号またはモード ID
  --scale machine|original|WxH
  --aspect stretch|keep|keep-nopad|crop
  --crop-pos X,Y   --crop-zoom F      切り抜き位置 (0〜100%) と拡大率 (指定すると切り抜きモード)
  --filter lanczos|bilinear|area|nearest
  --dither none|bayer2|bayer4|bayer8|fs|jjn|stucki|atkinson|sierra|sierralite
  --strength 0-100   --no-serpentine
  --tiling off|checker|quad|fine|vstripe|hstripe   --style free|88|98
  --colors N|65536|full   --metric rgb|lab   --no-black   --no-tile-constraint
  --no-linear                 混色を sRGB で計算 (既定は線形光)
  --brightness N --contrast N --saturation N --gamma F
  --alpha flatten|keep|binary --bg RRGGBB --threshold N
  --format png|jpg|gif|bmp|webp|mag  --quality N  --par  --zoom N
  --mag-user NAME --mag-memo TEXT --mag-machine XXXX
```

例:

```
RetroImageConvCLI photo.jpg -p 98 -o photo98.png
RetroImageConvCLI photo.jpg -p 88 -m d8 --tiling quad --style 88 --par -o photo88.png
RetroImageConvCLI photo.jpg -p 98 -o photo.mag --mag-user myname --mag-memo "テスト"
RetroImageConvCLI old.mag -p HD --scale original -o old.png
RetroImageConvCLI photo.jpg -p X68K --crop-pos 30,0 --crop-zoom 1.5 -o face.png
```

## アイコン

アプリのアイコン（`src/res/RetroImageConv.ico`）は本プロジェクトのオリジナルです。タイリングの空と夕日を映したドット絵のモニターで、
`tools/make_icon.py`（要 Pillow）で再生成できます。16/32/48/64/128/256 ドットを収録しています。
