# プリセット一覧

`RetroImageConvCLI --list` と同じ内容です。機種名は略称で表記しています。数値は一般に知られた画面仕様の概略で、固定パレットの RGB 値は本ソフト独自の近似値です。

「ドット比」は 1 ドットの 幅÷高さ です（0.5 = 縦長 2:1）。「[8x8毎 16色, パレット16本]」のような表記は、タイル（属性）単位の色制約を表します。
